JOGO DA VIDA - CORPO DE BOMBEIROS
Versão convertida para HTML, CSS e JavaScript puro.

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html em qualquer navegador moderno.

ARQUIVOS
- index.html: estrutura da página
- style.css: aparência e responsividade
- script.js: funcionamento da roleta, resultado e histórico
- assets/logo-bombeiros.png: logotipo

Não é necessário instalar Node.js, React, Vite ou qualquer dependência.
